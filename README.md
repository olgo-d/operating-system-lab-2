# Operating Systems Lab 2

Лабораторная работа №2 по курсу «Операционные системы».

Вариант 2: родительский процесс передаёт через pipe строки с произвольным
количеством чисел типа `float`. Дочерний процесс вычисляет сумму чисел
каждой строки и записывает результаты в указанный файл.

Используемые механизмы POSIX:
- `fork`
- `pipe`
- `dup2`
- `exec`
- `waitpid`
- `read` / `write`

Исходный код расположен в `inc/`, исходники отчёта — в `src/`.

Сборка отчёта:

```bash
make pdf
```

## Сборка и запуск программы

Для сборки программы необходимы CMake и компилятор C.

Из корневой директории репозитория выполните:

```bash
cmake -S inc -B build
cmake --build build
```

После сборки перейдите в директорию с исполняемыми файлами и запустите родительский процесс:

```bash
cd build
./parent
```

Первой строкой необходимо ввести имя выходного файла. Затем вводятся
строки с произвольным количеством чисел типа float, разделённых пробелами.
пример:
```bash
result.txt
1.5 2.5 3
10 20.5
4.5
```

Для завершения ввода в Linux используется:
```
Ctrl+D
```

## Трассировка системных вызовов

```bash
cd build
strace -f -tt -s 200 -o strace.log ./parent
```
